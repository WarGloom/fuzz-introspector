## 2024-05-18 - Optimized `os.walk` Directory Traversals
**Learning:** Preventing `os.walk` from descending into heavily populated, excluded directories (like `.git` or massive build folders) provides a massive I/O performance boost. Doing this by replacing `dirnames[:] = [...]` in-place directly stops the traversal at the branch, avoiding all subsequent stat and readdir syscalls. Also, using `tuple(extensions)` for `str.endswith()` leverages Python's C backend and avoids costly internal list iterations.
**Action:** Always verify `os.walk` traversals for opportunities to eagerly prune `dirnames` using `in-place` list assignment when dealing with known exclude lists. Avoid `pathlib.Path(filename).suffix in ...` in hot loops, and instead use `.endswith(tuple)`.
