## 2024-05-14 - Python Recursive Traversals on tree-sitter ASTs
**Learning:** `tree-sitter` parses code into potentially deep Abstract Syntax Trees (ASTs). When processing these AST nodes using recursive functions in Python, we incur significant function call overhead and run the risk of hitting Python's recursion limit, leading to `RecursionError` crashes on complex source files.
**Action:** Always favor iterative stack-based traversals (using `while stack: curr = stack.pop(); ... stack.extend(curr.children)`) over recursive traversals when aggregating metrics (like instruction counts or complexity) across an AST. This approach is not only safer but also consistently faster in Python.
